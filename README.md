# ذاكِر — مساعد مذاكرة موجّه للاختبار

تطبيق ويب **يعمل على جهازك فقط**: ترفع ملفات المادة واختبارات الدكتور السابقة، فيلخّص لك المادة ويشرحها بالعربي، ويحلّل أسلوب الدكتور، ويولّد أسئلة بنفس أسلوبه، ويصحّح إجاباتك ويتابع أخطاءك، ويبني لك خطة مذاكرة حتى يوم الاختبار.

**كل معلومة مربوطة بمصدرها** (الملف + رقم الصفحة) ومأخوذة من ملفاتك فقط. إذا لم تكن المعلومة في ملفاتك يقول لك ذلك صراحة.

## الميزات

- **رفع الملفات:** PDF وصور، مع استخراج النص العربي والإنجليزي صفحة صفحة. الصفحات المصوّرة تُقرأ بالذكاء الاصطناعي.
- **الشباترات:** تقسيم تلقائي للمادة إلى شباترات ومواضيع، قابل للتعديل يدويًا.
- **الملخصات:** ملخص سريع وآخر مفصّل لكل شابتر، والضغط على أي مرجع يفتح الصفحة الأصلية.
- **أسلوب الدكتور:** تحليل اختباراته السابقة (أنواع الأسئلة، توزيعها على الشباترات، المواضيع المتكررة) مع درجة ثقة.
- **توليد الأسئلة:** أسئلة بأسلوب الدكتور، وكل سؤال يُراجَع مقابل مصدره قبل أن يظهر لك.
- **وضع الاختبار:** بوقت أو بدونه، مع تصحيح فوري، وتقييم للإجابات المقالية يبيّن النقاط الناقصة، وشرح لماذا كانت إجابتك خاطئة.
- **اسأل المادة:** أسئلة وشرح بالفصحى أو باللهجة السعودية، من ملفاتك فقط.
- **سجل الأخطاء:** تكرار متباعد (Leitner) وصفحة «اليوم»، مع نقاط ضعفك حسب الشابتر والموضوع.
- **خطة المذاكرة:** خطة يومية من تاريخ الاختبار ونطاقه ووقتك، تتكيف تلقائيًا مع التأخير ونقاط الضعف.

## المتطلبات

1. **Node.js 22 أو أحدث**، من [nodejs.org](https://nodejs.org).
2. **اشتراك Claude** (Pro أو Max) و**Claude Code** مثبّتًا ومسجّل الدخول. التطبيق لا يحتاج مفتاح API: يستخدم Claude Code باشتراكك أنت، وكل مستخدم يستهلك من اشتراكه الخاص.

ثبّت Claude Code (في PowerShell على ويندوز اكتب `npm.cmd` بدل `npm`):

```bash
npm install -g @anthropic-ai/claude-code
```

ثم سجّل الدخول:

```bash
claude auth login
```

## التثبيت والتشغيل

**1. حمّل المشروع:** إما بالزر الأخضر **Code ← Download ZIP** في صفحة المستودع ثم فك الضغط، أو بـ git:

```bash
git clone <رابط المستودع>
```

**2. ادخل مجلد المشروع وثبّت الحزم** (مرة واحدة فقط):

```bash
cd zakir
npm install
```

**3. تأكد أن Claude Code يعمل مع التطبيق:**

```bash
npm run check:claude
```

**4. شغّل التطبيق:**

```bash
npm run dev
```

**5. افتح في المتصفح:** http://127.0.0.1:5173

للإيقاف اضغط `Ctrl + C` في الطرفية.

## طريقة الاستخدام المقترحة

1. أنشئ مادة، وأضف الاختبار بتاريخه.
2. ارفع ملفات المادة كـ«محتوى»، واختبارات الدكتور السابقة كـ«اختبار سابق». السلايدات حوّلها إلى PDF أولًا.
3. اضغط «تقسيم تلقائي» للشباترات، وحدّد الشباترات الداخلة في الاختبار.
4. ولّد الملخصات، وحلّل أسلوب الدكتور، ثم ولّد الأسئلة وتدرّب عليها.
5. أنشئ خطة المذاكرة من رابطها تحت الاختبار، وتابع يومك من صفحة «اليوم».

## الخصوصية

- كل بياناتك (الملفات وقاعدة البيانات) تُحفظ في مجلد `data/` داخل المشروع على جهازك، ولا تُرفع لأي مكان.
- النص الذي يحتاجه الذكاء الاصطناعي يُرسل إلى Claude عبر Claude Code باشتراكك، مثل أي محادثة عادية معه.
- الخادم يستمع على `127.0.0.1` فقط، فلا يصل إليه أحد من الشبكة.

## ملاحظات

- **مُختبَر على:** Windows 11 مع Node.js 24. أنظمة macOS وLinux غير مختبرة بعد.
- **أوامر مفيدة:**
  - `npm test`: الاختبارات (لا تستهلك اشتراكك).
  - `npm run extract -- ملف.pdf`: يعرض النص الذي سيُستخرج من ملف PDF قبل رفعه.
- **مسار `claude` غير معتاد؟** إن لم يجد التطبيق برنامج `claude`، انسخ `.env.example` إلى `.env` واكتب مساره في `CLAUDE_BIN`.
- **ملف `CLAUDE.md`** يوثّق قرارات التصميم والتفاصيل التقنية لمن يريد التطوير.
